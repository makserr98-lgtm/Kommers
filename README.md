# Хаб КП

Мобильное приложение для разбора коммерческих предложений: дерево вопросов, задачи по этапам 005–030, проверка формулировок, долги срочных работ.

Открыть на телефоне: https://makserr98-lgtm.github.io/Kommers/ → в Chrome «Добавить на главный экран».

Данные хранятся только в браузере телефона и никуда не отправляются. В репозитории только код.

- `index.html`, `sw.js`, `manifest.webmanifest`, иконки — само приложение (GitHub Pages).
- `src-kp-hub.html` — исходник страницы без обёртки.
